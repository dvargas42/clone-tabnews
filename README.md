# clone-tabnews

Um projeto para aprender uma implementação real de um site de conteudos sobre tecnologia.

O instalador do Obsidian para Windows fica em `public/downloads/` e pode ser baixado pela página inicial. Os arquivos `.exe` são versionados com Git LFS. Com o Git LFS instalado, execute `git lfs pull` após clonar o repositório para baixar o instalador completo.
